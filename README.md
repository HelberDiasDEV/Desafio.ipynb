#  Desafios de Python — Fundamentos e Bibliotecas

Repositório criado para registrar minha evolução nos estudos de **Python**, reunindo desafios práticos desenvolvidos utilizando o **Google Colab**.

Os exercícios têm como objetivo colocar em prática conceitos fundamentais da linguagem, além da utilização de bibliotecas e funções para resolver problemas de diferentes contextos.

##  Objetivos

* Praticar os fundamentos da linguagem Python;
* Desenvolver raciocínio lógico e capacidade de resolução de problemas;
* Aprender a utilizar bibliotecas Python;
* Trabalhar com listas e seus elementos;
* Gerar números e escolhas aleatórias;
* Realizar cálculos matemáticos;
* Trabalhar com entrada e saída de dados;
* Aplicar os conhecimentos em pequenos problemas práticos.

##  Conteúdos praticados

###  Aquecimento

* Instalação e utilização de bibliotecas;
* `NumPy`;
* `Matplotlib`;
* Importação de módulos e funções;
* Geração de números aleatórios;
* Biblioteca `random`;
* Função `randrange()`;
* Biblioteca `math`;
* Função `pow()`;
* Entrada de dados com `input()`;
* Conversão de tipos com `int()`.

###  Aplicando a projetos

Os desafios simulam situações práticas, como:

*  Sorteio de participantes;
*  Geração de tokens de acesso;
*  Seleção aleatória de frutas;
*  Manipulação e análise de listas numéricas;
*  Cálculo e identificação de raízes inteiras;
*  Cálculo de área de círculos;
*  Cálculo de valores comerciais;
*  Formatação de mensagens utilizando f-strings.

##  Evolução

Este repositório faz parte da minha jornada de aprendizado em **Python**, servindo como registro prático da evolução dos meus conhecimentos.

A ideia é começar pelos fundamentos e evoluir progressivamente para problemas mais complexos, desenvolvendo uma base sólida para aplicações futuras em **Backend, Análise de Dados, Data Science e automação**.

Cada desafio representa uma etapa do processo de aprendizado e busca transformar conceitos teóricos em código funcional.
